# Delali Portfolio

A modern digital portfolio built with HTML, CSS, and JavaScript.

This site showcases:
- Code-first development projects with GitHub repositories and live demos
- Platform and media case studies (Wix website, promo video, and interactive presentation)
- Personal profile details, skills, and social links

The visual direction uses a cyber-feminine theme with a black and hot pink palette, glass-style cards, smooth scroll sections, and interactive effects.

## Live Sections and Navigation

The header menu links directly to these sections in this order:
1. Home
2. About
3. Projects
4. Case Study
5. GitHub (Contact section)

On-page section IDs used for navigation:
- #home
- #about
- #projects
- #case-studies
- #contact
